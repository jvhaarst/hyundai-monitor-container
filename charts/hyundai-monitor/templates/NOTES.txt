Watch it take its first reading:

  kubectl -n {{ .Release.Namespace }} logs -f deployment/{{ include "hyundai-monitor.fullname" . }}

Confirm the two-year history is still intact, not replaced by a new one:

  kubectl -n {{ .Release.Namespace }} exec deployment/{{ include "hyundai-monitor.fullname" . }} -- \
    sh -c 'for f in monitor.csv monitor.dailystats.csv monitor.tripinfo.csv; do echo "$f: $(wc -l < $f) lines, $(sed -n 2p $f | cut -c1-19)"; done'

The first data row must still be 2024-04-01 (monitor.csv), 20240303
(dailystats) and 20240102 (tripinfo).
{{ if not .Values.persistence.existingClaim }}
Seed the volume from the host before the first real run:

  helm upgrade --install {{ .Release.Name }} ... --set collector.enabled=false --set shell.enabled=true
  POD=$(kubectl -n {{ .Release.Namespace }} get pod -l app.kubernetes.io/component=shell -o name | head -1)
  for f in monitor.csv monitor.dailystats.csv monitor.tripinfo.csv monitor.lastrun; do
    kubectl -n {{ .Release.Namespace }} cp "$f" "{{ .Release.Namespace }}/${POD#pod/}:/data/$f"
  done
  helm upgrade --install {{ .Release.Name }} ... --set collector.enabled=true --set shell.enabled=false
{{ end }}
